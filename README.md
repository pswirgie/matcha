## 1. Description
This project is a dating web application built with micro-framework.

Current Progress
- Configuration with Vite
- Clean frontend/backend separation using Docker
- Integration of the SQLite database
- User registration flow
- Login / authentication (Cookie / Token)
- Email verification
- Logout
- Password reset
- Password security (hashing with bcrypt)
- Search bar

Next Steps
- Matching algorithm
- Popularity score (Fame rating)
- Navigation with filters/sorting

## 2. Instructions
Run in local :
1. `make install`
2. `make logs-frontend` -> click on localhost link
